# 🛎️ Bipli

> نظام نداء ذكي للطلبات — من الكاشير إلى هاتف العميل في ثانية.

نظام لحظي يعتمد على **Node.js** + **Socket.io** يتيح للكاشير إنشاء طلب وإصدار QR،
وللعميل مسح الـ QR لتتبع حالة طلبه واستلام تنبيه صوتي فور جاهزيته.

## ✨ الميزات

- 🎯 إنشاء طلب في ثانية مع QR تلقائي
- 📡 تتبع لحظي لحالة الطلب (انتظار ← تحضير ← جاهز)
- 🔔 تنبيه صوتي + اهتزاز + إشعار نظام على هاتف العميل
- 📱 PWA قابلة للتثبيت على الشاشة الرئيسية
- 🌐 يعمل على الشبكة المحلية بسهولة
- 🎨 واجهة عربية أنيقة ومتجاوبة
