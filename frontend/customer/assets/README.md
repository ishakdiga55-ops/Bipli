# مجلد الأصول — Bipli

## الملفات المطلوبة

### 1) `ringtone.mp3`
- ملف صوتي قصير (2-5 ثوانٍ) يتكرر تلقائياً.
- أي ملف mp3 يعمل. اختر نغمة واضحة وسهلة السماع.
- **اختياري**: إن لم يوجد، يعمل النظام تلقائياً على نغمة "بيب" مولّدة عبر Web Audio API.

### 2) أيقونات PWA
- `icon-192.png` (192×192)
- `icon-512.png` (512×512)
- **اختياري**: إن لم توجد، يعمل التطبيق لكن المتصفح قد يشتكي في الـ Console.

## كيف تحصل على الأصول؟

- **نغمة**: حمّل أي نغمة من [pixabay.com/sound-effects](https://pixabay.com/sound-effects/) (مجانية).
- **أيقونات**: استخدم [favicon.io](https://favicon.io/) أو [realfavicongenerator.net](https://realfavicongenerator.net/).
